# FinSight AI --- Finance News Insight

FinSight AI is an educational Flask web application combining a market
dashboard, financial-news RSS feeds, machine-learning sentiment
classification, and an optional local large language model (LLM)
explanation.

> **Disclaimer:** This project is for educational and informational
> purposes only. Sentiment predictions are experimental and are not
> investment advice, price forecasts, or recommendations to buy or sell
> securities.

## Features

-   **Market dashboard:** Displays the S&P 500, QQQ, Dow Jones, Russell
    2000, VIX, US Treasury yields, gold, WTI crude oil, and Bitcoin.
-   **Financial-news feed:** Collects headlines and summaries from
    configured CNBC and Reuters RSS feeds, deduplicates stories, and
    filters some low-value results.
-   **Sentiment classification:** Uses TF-IDF and Multinomial Naive
    Bayes to classify text as positive, negative, or neutral.
-   **Class probabilities:** Displays the classifier's estimated
    probabilities for each sentiment.
-   **Local AI explanation:** Optionally uses a locally running Ollama
    model to explain the story and its possible investor relevance.
-   **Evaluation report:** Saves accuracy, macro F1-score, a
    classification report, and a confusion matrix to
    `model_evaluation.txt`.

## Technology Stack

-   Python and Flask
-   pandas, scikit-learn, and joblib
-   yfinance for market data
-   feedparser and requests for RSS feeds and HTTP requests
-   Ollama for optional local LLM explanations
-   FRED data for Treasury yields, as implemented in `market_data.py`

## Setup (Windows PowerShell)

Run these commands from the project directory.

### 1. Create and activate a virtual environment (recommended)

``` powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

If activation is blocked by PowerShell, use the same Python installation
consistently for installing dependencies, training, and running the app.

### 2. Install dependencies

``` powershell
python -m pip install --upgrade pip
pip install -r requirements.txt
```

### 3. Train the sentiment model

``` powershell
python -m py_compile model_training.py
python model_training.py
```

This generates or updates `sentiment_model.pkl`, `vectorizer.pkl`, and
`model_evaluation.txt`.

The current demonstration dataset contains 165 constructed examples: 55
positive, 55 negative, and 55 neutral. These examples are for
educational use and are not a representative sample of real financial
news.

### 4. Run the web application

``` powershell
python app.py
```

Open http://127.0.0.1:5000 in your browser. Stop the development server
with `Ctrl+C`.

## Optional: Ollama Setup

Install Ollama separately and download the model configured by the app.
The default model is `llama3.2:1b`.

``` powershell
ollama pull llama3.2:1b
```

If Ollama is not already running as a background service, start it with:

``` powershell
ollama serve
```

Optional environment variables:

``` powershell
$env:OLLAMA_MODEL = "llama3.2:1b"
$env:OLLAMA_URL = "http://localhost:11434/api/chat"
```

The LLM explanation is separate from the classifier prediction. It can
make mistakes; check the original article for context.

## How to Use

1.  Open the dashboard.
2.  Review the market indicators and financial-news headlines.
3.  Select a news item for analysis or paste a financial
    headline/excerpt into the input form.
4.  Submit the text to view the predicted sentiment and class
    probability estimates.
5.  Read the optional local LLM explanation if Ollama is available.
6.  Review `model_evaluation.txt` for the model's test metrics.

The app analyzes the submitted headline and available summary, not
necessarily the full original article.

## Model and Evaluation

The classifier uses:

-   `TfidfVectorizer(ngram_range=(1, 2), max_features=5000, sublinear_tf=True)`
-   `MultinomialNB(alpha=0.5)`
-   A stratified 75% training / 25% test split with `random_state=42`

The latest recorded run on the 165-example demonstration dataset
reported:

-   **Test accuracy:** 52.38%
-   **Macro F1-score:** 0.5232

These results come from a small constructed dataset and a single
train/test split. They do not establish reliable performance on
real-world financial news. The model's probability outputs should not be
treated as calibrated confidence.

## Data Sources and Limitations

-   Market prices are retrieved through `yfinance`, as implemented in
    `market_data.py`.
-   Treasury yield observations are retrieved from FRED, as implemented
    in `market_data.py`.
-   Headlines and summaries come from the RSS feeds configured in
    `news_feed.py`.
-   Third-party services may be delayed, unavailable, rate-limited, or
    change their feed formats.
-   Some feeds may still include stock-profile or low-value entries
    despite filtering.
-   This is an educational prototype, not a production-grade financial
    analytics system.

## Troubleshooting

**Model files are missing:** Run `python model_training.py`.

**Ollama is unavailable:** Check that Ollama is running and that the
configured model is installed. Sentiment classification is separate from
the LLM explanation.

**Market data or news does not load:** Check the internet connection and
retry. Third-party providers can be temporarily unavailable.

**Dependency errors:** Use the same Python environment for installation,
training, and running the app:

``` powershell
python -m pip install -r requirements.txt
python model_training.py
python app.py
```
